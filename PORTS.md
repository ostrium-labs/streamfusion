# Ported files

Loams Stream ports code file by file from other Apache-2.0 projects, chiefly Arroyo
(`ostrium-labs/arroyo`, frozen for provenance) and RisingWave (`ostrium-labs/risingwave`). Each
ported file keeps its original copyright lines and gets one row here (Loams design 82, §5.5).
Nothing is ported from a RisingWave module gated by its licence key, and no code under AGPL, BSL,
FSL, SSPL or ELv2 is ported.
